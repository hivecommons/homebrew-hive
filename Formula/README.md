# Generated formulae — do not hand-edit

This directory is generated by the Apptainer conversion workflow from a specific
`ghcr.io/hivecommons/hive-contributor` digest.

- `contribute.rb` tracks the stable channel and installs `hive-contribute`.
- `contribute-candidate.rb`, when generated, tracks the candidate channel and
  installs `hive-contribute-candidate` for pre-release validation.

If a formula is wrong, fix `scripts/generate-formula.py` or
`.github/workflows/convert.yml`; the next conversion run overwrites manual
formula edits.
