# Generated formulae — do not hand-edit

This directory is an **output**. Formulae here are generated by the Apptainer
conversion workflow from a specific `ghcr.io/hivecommons/hive-contributor`
digest, and any manual edit is overwritten by the next release.

If a formula is wrong, fix the generator, not the artifact.

It is empty until Phase 2 of the
[contribute distribution roadmap](https://github.com/hivecommons/hive/blob/v4/docs/contribute-distribution-roadmap.md)
unblocks — see the repository README for what that is waiting on.
